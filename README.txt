JARVIS V4.4 音声JARVIS統合版

追加機能
・トップ画面にJARVIS音声コマンド
・PC / スマホ対応（対応ブラウザではマイク許可が必要）
・文字入力でも同じ操作が可能
・音声で画面移動、売上/粗利/不足/欠車確認
・音声で案件の稼働台数/必要台数/欠車/月実績を変更
・「保存して」で端末内保存
・「配送管理をダウンロード」でCSV出力
・既存の編集/保存/再読込/配送管理DL機能は維持

GitHubで index.html / app.js / style.css / sw.js / jarvis-v4-data.json / manifest.json を上書きして Commit changes。

注意：音声認識はブラウザ対応状況に依存します。iPhoneではSafari系、PCではChrome/Edge系での利用が比較的安定します。
