# JARVIS 売上・利益管理仕様（2026-09）

## 完成基準
配送管理表の実績を正本として、JARVISで以下を表示・回答できること。
- 今日の売上
- 今月売上
- DR支払額
- 粗利
- 粗利率
- 拠点別・案件別内訳
- 未確認単価／DR金額の件数
- 欠車による売上・粗利影響（確認済み単価のみ）

## 原則
1. 原本・元データは変更しない。
2. 対象は実運用版の配送管理表。
3. 未確認の単価、DR単価、残業、サーチャージ、インセンティブ、特殊ルールは推測しない。
4. 売上とDR支払の両方が確定した行だけ粗利を確定する。
5. 未確定行は0円扱いにせず「未確認」として件数を表示する。

## データフロー
Googleシフト正本 → JARVIS連携 → 配送管理表 実運用版 → JARVIS売上利益集計 → JARVIS画面/API

## 三島先行
三島は現在、走行日・DR・業務名・DR金額・実績・備考まで自動連携済み。まず三島の売上単価マスターと実績を結合して、日次／月次売上・DR支払・粗利を確定する。

## 他拠点
三島が安定後、一宮・中村区・静岡・鶴見・富士・野洲・その他へ順次展開。単価変更日や特殊条件がある拠点は期間別ルールで管理し、確認前は計算しない。

## UI
トップ画面に以下のカードを置く。
- 今日の売上
- 今月売上
- 今月DR支払
- 今月粗利
- 粗利率
- 未確認件数

数値は同一の集計ソースから取得し、画面とAI回答で一致させる。
